# Base Docker

> Template base com configuracao Docker para projetos PHP, incluindo containers de aplicacao (PHP-FPM) e servidor web (Nginx).

## Stack

- Docker

## Prerequisitos

- Docker e Docker Compose

## Como executar

```bash
# Clone o repositorio
git clone https://github.com/meirelesdev/base-docker.git
cd base-docker

# Inicie a aplicacao
docker-compose up -d
```
